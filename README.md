# Pantry Manager

I made this app to keep track of Filipino ingredients at home. You can browse staples like pandesal, bangus, kesong puti, kalamansi, and patis by category, adjust cart quantities, check the total, and add pantry items with their details.

To run it, use `npm install` and then `npm run dev`.

For the pre-final, I added product cards and detail pages, category filters, cart controls and totals, low-stock labels, and a form for adding ingredients. The data stays in React state while the app is open.
